# Plugin for WordPress with wooCommerce

tested on WordPress 7.0, 6.9.1, 6.8.3, 6.6.  
with WooCommerce 9.5.1, 9.3.4, 8.7.0, 7.1.2.

# Installation and configuration

1. In admin section "Improve" click "Module Manager"
2. Then "Upload a module"
3. And select or drag file "payneteasypayment.zip"<br><img src="installation/1-3.png" alt="plugin installation steps 1-3" width="450"/>
4. After installation completed, click "Configure"<br><img src="installation/4.png" alt="plugin installation step 4, configuration" width="450"/>
5. And then after filling necessary parameters, click "Save"<br><img src="installation/5.png" alt="plugin installation step 5, saving configuration" width="450"/>
6. Installation and configuration completed.
